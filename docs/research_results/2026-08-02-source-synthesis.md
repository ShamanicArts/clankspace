# Source synthesis

- **shuv2code:** typed commands, serialized orchestration, events plus projections, receipts, provider-neutral sessions, and runtime recovery.
- **Auto-biz:** explicit rationale, supersession history, SQLite authority, request IDs, expected revisions, and professional handoffs.
- **Buzz:** agent-first identity, shared event log, bounded tools, and project/branch context.
- **Beads:** compact agent instructions, JSON CLI, persistent memory, doctor, and sync ergonomics.
- **ClankSpace correction:** retain these mechanics while rejecting the idea that recorded decisions become canonical project law.
